# CCK

Website for Creative Coding Kortrijk (CCK), a (fictional) creative coding community in Kortrijk. Built with [Astro](https://astro.build) as a team assignment for WEB 3 at Devine (Howest).

## Getting started

```sh
npm install
npm run dev
```

The dev server runs at <http://localhost:4321>.

| Command           | Action                                 |
| ----------------- | -------------------------------------- |
| `npm run dev`     | Start the dev server                   |
| `npm run build`   | Build the site to `dist/`              |
| `npm run preview` | Preview the build locally              |

## Project structure

- `src/pages/`: routes (home, about, news and detail pages for foundations, team and workshops)
- `src/content/`: Markdown content for the `foundations`, `news`, `team` and `workshops` collections, defined in `src/content.config.ts`
- `src/components/` and `src/layouts/`: Astro components and layouts
- `src/styles/`: plain CSS (reset, global styles and design tokens)
